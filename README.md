# BehaveScope · 离线软件行为分析器

> 一条命令，离线分析任何软件/样本的行为，输出可提交的分析报告。
> 面向 CTF 现场 / 应急响应 / 红队对抗 / 护网值守 —— 无外网也能完成完整分析闭环。

**作者**: x7peeps · **策略**: 纯本地离线 · **平台**: Windows 优先，跨平台（macOS/Linux）

---

## 定位

比赛现场 / 应急现场通常**无外网**，拿到样本（exe/elf/apk/脚本/流量包/内存镜像）后需要快速回答：

- 这个程序**做了什么**？（文件 / 网络 / 进程 / 注册表行为链）
- 它**恶意吗**？（规则命中 + 行为判定 + 可选本地 AI 解读）
- 攻击**痕迹**在哪？（内存取证 / 启动项 / 服务 / 计划任务）
- 对手的 **C2 / webshell / 隧道**流量什么样？（pcap 分析）

BehaveScope 把这些能力压缩成**一条命令**，自动识别样本类型 → 路由到对应引擎 → 输出 `report.json` + `report.md`（可直接提交比赛 / 归档）。

## 快速开始

```bash
# 分析单个样本（自动识别类型）
behave sample.exe

# 分析内存镜像
behave mem.dmp

# 分析流量包
behave traffic.pcap

# 批量分析目录
behave C:\suspicious\
```

产物：
- `report.json` — 结构化报告（机器可读）
- `report.md` — 人类可读报告（可提交比赛）
- `evidence/` — 原始证据（dump / 截图 / 提取物）

## 能力矩阵

| 引擎 | 输入 | 输出 |
|---|---|---|
| 静态引擎 | PE/ELF/Mach-O/APK/脚本 | 哈希/熵/加壳/字符串/导入表/YARA 命中/关键 API 序列 |
| 动态引擎 | 可执行样本 | 沙箱隔离运行 → 文件/网络/进程/注册表行为链 |
| 取证引擎 | 内存镜像 / 已中招机器 | 进程/连接/注入痕迹/启动项/服务/计划任务 |
| 流量引擎 | pcap | C2 通信 / webshell 流量 / 隧道特征 |
| 报告引擎 | 以上全部 | 行为证据链 → 自动判定 → 可提交报告 |

## 离线三要素

1. **纯本地运行**：所有引擎本地调用，无云端 API 依赖
2. **内置规则库**：YARA 规则 + 行为特征规则随工具打包
3. **AI 可选降级**：内置本地 LLM（Qwen 量化 + llama.cpp）做行为解读；无模型时自动降级纯规则判定
